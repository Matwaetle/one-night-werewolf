# 🐺 한밤의 늑대인간 온라인

친구들과 웹 브라우저로 함께하는 **한밤의 늑대인간(One Night Ultimate Werewolf)**입니다.
3~10명이 각자 휴대폰이나 PC로 접속해서 플레이합니다. 음성 통화(디스코드 등)를 켜고 하면 더 재밌어요.

## 기능

- 방 만들기 / 4자리 코드 또는 초대 링크로 참가
- 기본판 역할 12종 전부: 도플갱어, 늑대인간, 하수인, 프리메이슨, 예언자, 강도, 말썽쟁이, 주정뱅이, 불면증환자, 마을주민, 사냥꾼, 무두장이
- 방장이 사용할 카드 구성 선택 (인원에 맞는 추천 구성 자동 적용)
- 밤: 역할 순서대로 자동 진행, 내 차례에만 행동 화면 표시 (선택하면 음성 나레이션)
- 낮: 토론 타이머, 채팅, 투표 준비 / 방장의 바로 투표
- 투표 → 사냥꾼, 무두장이 등 공식 규칙대로 승패 판정
- 결과 화면: 모든 카드 공개, 밤에 일어난 일 전체 기록
- 새로고침하거나 연결이 끊겨도 같은 브라우저로 다시 들어오면 이어서 플레이
- 역할은 서버만 알고 있어서, 브라우저 개발자 도구로 남의 카드를 훔쳐볼 수 없음

## 실행하기 (내 PC)

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

**가장 쉬운 방법:** `시작.bat`을 더블클릭하세요.

또는 터미널에서:

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열면 됩니다.

## 친구들과 온라인으로 하기

서버를 켠 PC 말고 다른 사람도 들어오려면 아래 중 하나를 고르세요.

### 1. 같은 와이파이에 있을 때

서버 PC의 IP 주소(예: `192.168.0.10`)로 접속합니다: `http://192.168.0.10:3000`
(IP는 `ipconfig`로 확인. Windows 방화벽이 물어보면 허용하세요.)

### 2. 인터넷으로 바로 공유 (가입 필요 없음)

[cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)를 설치한 뒤, 서버를 켠 상태에서:

```bash
cloudflared tunnel --url http://localhost:3000
```

`https://xxxx.trycloudflare.com` 같은 주소가 나옵니다. 이 주소를 친구들에게 보내면 됩니다.
(서버 PC를 끄면 접속이 끊깁니다.)

### 3. 항상 켜져 있는 사이트로 배포 (무료)

[Render](https://render.com) 같은 Node.js 호스팅에 올리면 PC를 켜두지 않아도 됩니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render에서 **New → Web Service** → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. 배포가 끝나면 나오는 주소를 공유하면 끝!

(무료 요금제는 한동안 접속이 없으면 잠들어서 첫 접속이 30초쯤 걸릴 수 있습니다.)

## 게임 시간 조절

`server.js` 위쪽의 `T` 값을 바꾸면 밤 행동 제한 시간 등을 조절할 수 있습니다.
낮 토론 시간은 게임 대기실에서 방장이 고릅니다.

## 테스트

```bash
npm test
```

봇 여러 명이 3~10인 게임을 자동으로 끝까지 플레이하면서 규칙과 비밀 정보 보호를 확인합니다.

## 파일 구조

```
server.js          게임 서버 (방, 밤 진행, 투표, 승패 판정)
public/index.html  웹 페이지
public/app.js      화면과 조작
public/style.css   디자인
public/roles.js    역할 데이터 (서버와 브라우저가 같이 사용)
test/sim.js        자동 플레이 테스트
```
